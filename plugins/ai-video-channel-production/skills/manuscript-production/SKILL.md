# 文稿中心

只形成可以进入发布素材准备的唯一正式口播内容。不要生成正式标题、简介、Hashtags 或封面，不要调用工坊、授权、上传或数据中心。

## 进入与输入冻结

1. 调用 `content_capabilities`，确认 Manuscript Package v1 和目标语言规则可用。
2. 调用 `content_project_get`。只接收状态已确认、哈希与来源链通过的 Topic Package v1；未确认选题、坏哈希或上游版本错配必须停止。
3. 冻结 Story Bible：故事事实、世界规则、人物关系、时间线、伏笔、高潮、结局和逐集推进。
4. 冻结主要角色包：只包含主角、主要反派、持续出场重要配角的目标语言姓名、目标、关系、说话特征和视觉锚点。
5. 调用 `system_voice_catalog` 读取预扫描真实目录，为实际配音角色绑定已安装引擎、voice ID 和名称。不得启动工坊扫描，不得手写不存在的音色。

本次用户明确指令优先于已锁定频道学习快照，但只作为项目级覆盖。若用户改变主线事实、人物关系、结局、核心题材或集数，返回 `$topic-selection` 建立上游新版本，不能在文稿阶段静默改大纲。

## 唯一母稿与逐行结构

- 直接用目标地区的目标语言原生写作，不先写完整中文稿再翻译。
- 目标语言正式母稿是配音、字幕、分镜和包装事实核验的唯一内容事实源。
- 每行必须有稳定 `lineId`、`episode`、连续集内 `order`、可选连续 `globalOrder`、说话人、`narration|dialogue` 类型、情绪标签和完整可朗读文本。
- 每完成一集保存真实内容与状态；恢复时只补缺失或失败集，不无故重写已通过分集。

## 合并质量门

草稿完整后再审查。逐集用同一质量门检查：锁定事实与因果、真实推进和前后状态变化、人物声音、目标地区自然表达、术语一致、TTS 完整语义切分，以及目标观众能否复述焦点、进展、回报和继续观看或完整满足的理由。

失败时只定向修改有文本证据的失败集，最多三轮，并使该集下游回译失效；其他已通过集保持有效。质量门、目标篇幅容差、失败项、修复轮次、版本和 SHA-256 必须进入正式包。

## 中文审核稿与修改

- 非中文目标语言逐行回译成自然、忠实的中文审核稿，严格保持集、line ID、顺序、说话人、类型和情绪一一对应；不补写、不二次创作。
- 目标语言为中文时直接复用同一正式母稿，并标记“无需回译”，不生成重复稿。
- 检查缺行、多行、乱序、说话人变化、类型／情绪变化和语义明显缺失。任一映射错误都不能通过。
- 用户根据中文稿提出意见时，先定位并修改目标语言正式母稿，再重跑受影响集质量门、重新回译和映射检查。不得只改中文审核稿。

## 确认与冻结

1. 联合展示目标语言母稿、中文审核稿、质量门和映射结果。
2. 审核模式等待明确联合确认；自动模式只有全部硬门通过且当前项目已授权例行自动确认时才能确认。
3. 调用 `content_manuscript_finalize`，提交 Story Bible、角色与音色锁、正式母稿、审核稿、质量门、变更记录、上游引用和确认记录。
4. 只有工具返回 `SCRIPT_READY`（或契约定义的等价确认状态）且 `content_integrity_check` 通过时，才称为 Manuscript Package v1 已冻结。

## 永久边界

- 标题属于下游发布资产；标题修改不得改变母稿版本或哈希。
- 只读取频道学习快照。一次性修改只保存在本项目，不调用频道默认或长期学习写回。
- 不调用工坊、制作、Google／YouTube 授权、上传、发布回执或 Analytics。
