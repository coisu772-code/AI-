# 频道建库与绑定

## 0.1.0-beta.2 行为

执行只读前提检查并展示：

1. YouTube 发布中心是否已经安装。
2. 发布中心频道只读接口是否已在当前兼容清单中提供。
3. 频道身份契约是否包含 `channel_profile_id → publisher_profile_id → channel_serial → youtube_channel_id`。
4. 阶段 2 尚未实现时，明确返回 `NOT_IMPLEMENTED_STAGE_1` 并停止。

## 永久边界

- YouTube 发布中心是 OAuth、真实频道身份和频道序号的唯一事实源。
- 不要求用户向 Codex 粘贴 Token、Client Secret、Cookie、验证码或密码。
- 没有可用频道时，只引导用户前往发布中心添加频道；不创建假频道。
- 首次身份绑定只确认目标地区和输出语言。
- 建库阶段另确认默认配音、篇幅策略、集数策略和制作方式。
- 视频范围、发布时间与自动上传授权不是首次建库必填项。
- 一个对话只绑定一个 `channel_profile_id`；切换频道必须新建对话。
- 参考频道只能作为资料来源，不能进入目标发布身份链。

## 未来实现门

只有发布清单声明本地工具服务、频道读取协议和频道数据 Schema 兼容，并且真实只读工具可调用时，才允许进入建库写入。任何一项缺失都保持只读并列出缺口。
