# Packaging extension handoff

三个后续 Skill 共享同一输入：

- 已确认 Manuscript Package v1 引用、版本和 SHA-256；
- 目标频道、地区、语言、受众和平台；
- 唯一正式母稿与故事事实哈希；
- `packagingBrief` 中的核心冲突、最大回报、可视化任务和禁止虚构承诺。

预留输出：

- `content-title` → Title Asset v1；
- `content-description` → Description Asset v1；
- `content-thumbnail` → Thumbnail Asset v1。

三项完成后由现有 `$publishing-assets` 负责联合核验与汇总，不要求其中任一 Skill 改写正式母稿。
