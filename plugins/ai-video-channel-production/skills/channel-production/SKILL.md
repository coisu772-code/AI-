# AI 视频频道生产系统总入口

## 启动检查

1. 调用 `system_capabilities`，读取真实服务、协议、数据库和组件能力。
2. 显示系统管理中心状态：发布频道接口、预扫描音色目录、频道资料库、备份迁移与当前任务绑定。
3. 区分“可用”“需要用户处理”“当前未实现”，不要把插件加载成功等同于业务闭环成功。
4. 不读取或要求用户粘贴任何凭据。

## 阶段3路由

- 建立频道资料库、进入已有频道、修改生产默认值、仅本次覆盖、备份、恢复或迁移：调用 `$channel-onboarding`。
- 新任务开始生产前先确保当前任务只绑定一个 READY 频道，再读取活动 Production Profile。
- 添加、下载、导入、更新、检索、取消或恢复资料任务：调用 `$source-library`。资料库仍属于系统管理中心。
- 拆视频、拆书或仿写：只登记为后续可插拔能力。未入库时先用 `$source-library` 完成资料闭环；已入库时明确阶段4尚未执行。
- 选题、文稿、标题、简介、标签或封面：明确属于阶段4，当前阶段不生成。
- 工坊生产：明确属于阶段5，当前阶段不调用。
- 真实上传：明确属于阶段6；即使频道已授权也不得创建上传意图。
- Analytics、报告或长期频道学习：明确属于阶段7，当前阶段不执行。

## 输出状态卡

以普通用户能理解的语言显示：

1. 产品与本地工具版本。
2. 可用发布频道数量，或前往发布中心处理的动作。
3. 已有频道资料库及其 READY／待完成／需修复状态。
4. 当前任务是否已绑定唯一频道。
5. 下一项可执行动作。

查询状态必须只读，不得自动创建频道、切换任务绑定、修改默认值、恢复备份或进入后续中心。

## 永久边界

- 目标频道身份只来自 YouTube 发布中心的只读接口；参考频道永远是资料来源。
- 一个任务只绑定一个 `channelProfileId`；切换目标频道必须新建任务。
- 仅本次覆盖不得污染频道长期默认值；频道默认变更必须明确确认并生成新版本。
- 关闭 Codex 后，频道资料、预设和任务外状态继续由本地数据库保存。
- 发布授权、音色目录、资料库、工坊和上传状态分别判断，不能用一个故障宣称整个系统不可用。
