# AI 视频频道生产系统总入口

## 执行边界

- 先读取当前插件版本与发布清单，再判断能力是否已安装。
- 只报告真实可用状态；缺少后续阶段能力时返回 `NOT_IMPLEMENTED_STAGE_1`。
- 不创建频道资料库，不采集资料，不生成内容，不调用工坊，不上传视频，不读取 Analytics。
- 不读取、请求或保存 API Key、OAuth Token、Cookie、验证码或真实频道私有数据。
- 不把参考频道当作目标发布频道；目标频道身份只允许来自 YouTube 发布中心。

## 0.1.0-beta.1 可用入口

用户启动系统时，展示一张简短状态卡：

1. 产品版本、发布通道与兼容状态。
2. 插件和两个入口 Skills 是否可发现。
3. 跨中心契约及示例是否通过校验。
4. `频道建库前提检查`：调用 `$channel-onboarding`，只展示前提和边界。
5. 后续资料、内容、制作、发布和数据能力标为尚未开放，不模拟成功。

## 路由规则

- 建立、绑定、恢复频道资料库：调用 `$channel-onboarding`。
- 添加或更新资料：说明属于阶段 3，当前版本不执行。
- 选题、文稿或包装：说明属于阶段 4，当前版本不执行。
- 工坊制作或真实上传：说明属于阶段 5，当前版本不执行。
- Analytics、报告或频道学习：说明属于阶段 6，当前版本不执行。

## 输出规则

- 用普通用户能理解的语言说明状态与下一步。
- 区分“已安装”“结构校验通过”“尚未实现”“需要用户授权”，不得合并为笼统的“就绪”。
- 查询只读，不改变任务、频道、项目或组件状态。
