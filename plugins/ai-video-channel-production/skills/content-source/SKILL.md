# 内容来源

旧拆解和仿写方向能力已经移除；本 Skill 只取得来源，不用通用模型补做已移除步骤。

先读取 [逐阶段确认契约](../channel-production/references/manual-stage-confirmations.md)。把用户给出的链接或文本直接转换为可追溯的 Source Package。用户已经明确要求“下载、导入或保存这个资料”时，该请求就是本次来源取得授权；范围与原请求完全一致时，不再增加一次“确认入库”对话门，但它不构成后续写作授权。

## 输入路由

- 视频链接：优先取得人工字幕，其次自动字幕，最后才使用已配置的临时音频本地转录。
- 用户文件：支持当前能力清单声明的 TXT、MD、EPUB、PDF、DOCX、字幕、音频或视频文件。
- 粘贴文本：原样保留输入哈希，生成规范 UTF-8 正文。
- 本地资料库：检索并复用已有版本，不重复下载同一平台 ID、规范 URL 或内容哈希。
- 联网资料：只在用户要求搜索或融合资料时检索公开页面；记录页面 URL、标题、采集日期、可引用事实和未知项。受限正文不得绕过登录、付费墙、DRM、验证码或访问限制。
- 热点／趋势研究：必须使用当前公开网页，不得依赖记忆。按用户已经明确的地区、受众和题材范围检索，不重复询问这些值；对每个候选记录目标语言原词、中文解释、来源标题、可点击 URL、发布日期或页面时间、采集日期、公开趋势依据、置信度和事实边界。

## 热点选择卡交接

用户要求“先搜索、让我选择、选择后再写”时：

1. 先取得至少两类相互独立的公开证据；单一聚合页或搜索结果摘要不能独立证明“热门”。
2. 把候选交给总入口保存为 `用户审核文档/00_热点检索与创作素材选择.md`。每个候选使用独立 `H` 编号，并把新闻事实、热词表达和可用于虚构创作的冲突／情绪功能分开说明。
3. 没有链接、时间和公开依据时，不得输出“已完成检索”“当前热门”或按热度排序；证据不足的候选只能标记为“待验证”。
4. 选择卡展示后停在 `R0_RESEARCH_SELECTION`，等待用户选择。用户没有选择前不得写小说、生成大纲、生成图片／视频提示词或显示制作设置。
5. 用户文本存在错别字或多义项时，只澄清影响当前检索的部分；只影响后续创作或提示词类型的含糊项延迟到进入该步骤前确认，不阻塞本轮检索。

## 执行

1. 确认当前任务绑定的唯一 `channelProfileId`；没有频道时允许建立“未绑定草稿来源”或“未绑定研究来源”，但进入正式制作前必须绑定目标频道。
2. 调用 `source_library_capabilities` 核对来源类型。
3. 调用 `source_add_prepare`。若返回计划与用户原请求一致，立即调用 `source_add_confirm`；只有计划扩大下载范围、产生付费、需要登录或可能保存用户未授权内容时才暂停询问。
4. 查询使用 `source_job_get`，恢复使用 `source_job_resume`，完整性使用 `source_integrity_check`。状态查询只读。
5. 只把清洗后的唯一正文保存为 `normalized/.../content.txt`；字幕格式文件只作为临时输入。可另存 `timing-map.json`、`chapters.json` 和来源元数据。
6. 为规范正文建立连续 `paragraphId`；视频尽可能把 `paragraphId` 绑定时间范围，长文本把章节与段落范围写入 `chapters.json`。来源交接必须保留这些证据定位，不能只交一段主题摘要。
7. 采集方法必须按事实记录：实际取得人工字幕、自动字幕或本地转录时，分别记录对应方式；不得把已读取的字幕标成 `user_supplied_summary`，也不得用标题或简介的字符数冒充正文长度。

## 完成门

- `CONTENT_READY`：正文完整，来源任务结束；不自动交给拆解、方向推荐或正文生成。
- `PARTIAL`：显示缺失范围；用户明确接受后才允许拆解。
- `BLOCKED`：请求用户补充字幕、文字稿、音频、视频或本地文件；不得根据标题、封面、简介或评论编造正文。

旧内置拆解和仿写方向能力已经移除。用户只要求拆解或仿写方向、没有要求完整正文且没有当前任务提示词文件时，来源取得后说明旧能力不可用并停止；不得调用旧 `content-deconstruct`、旧 8 方向工具或用临时总结冒充拆解结果。用户已经主动提供一份或多份外部提示词文件时，来源取得后返回总入口登记 `task-prompt-guided` 合同；用户明确要求直接写完整正文时返回总入口判断 `direct-draft`，不得误判为方向请求。提示词正文不得复制进 Skill、插件资产或长期规则。字段约定见 [references/source-handoff.md](references/source-handoff.md)。

用户以后另行提供并确认不少于 80 字的创作简报／故事大纲时，可由总入口以 `provided-outline` 路线交给正文生成。用户已经明确要求直接写完整正文，并在当前任务提供完整来源、有效临时提示词或明确创作范围时，可由总入口以 `direct-draft` 路线交给正文生成；Source Package 仍不得冒充用户大纲，也不得在没有写作授权时自动触发创作。

## 边界

- 不分析结构，不生成仿写，不生成标题、简介或封面。
- 不询问或确认配音、音色、宫格、图片提示词、视频提示词、故事图片画风、成片方式、镜头视频范围或上传设置；这些只在用户明确开始制作后处理。
- 不把模糊的“提示词”解释成“视频提示词”，也不把“视频提示词”解释成实际生成视频。
- 不把完整字幕或正文压缩成抽象卖点后替代 Source Package，也不把来源采集与创作重构合并在同一步。
- 不启动工坊、发布、上传、Analytics 或长期频道学习。
- 原始文件、规范正文、分析结果和正式文稿必须分开存放，任何已被下游引用的版本不得覆盖。
