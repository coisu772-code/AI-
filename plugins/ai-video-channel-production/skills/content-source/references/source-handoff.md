# Source handoff

交给下游时只需要：

- `sourcePackageId`、版本、`contentHash`、状态和 `channelProfileId`；
- 来源类型、原始定位、语言、标题与采集时间；
- 唯一规范正文 `content.txt`；
- 连续段落 ID，以及可选的 `timing-map.json` 或 `chapters.json`；
- 实际采集方式、正文字符数、段落数、章节数与字幕覆盖范围；
- 完整性、已知缺口、事实／推断／未知边界。

下游必须以完整规范正文和段落／时间证据定位为依据。主题摘要、页面标题、简介或几个“核心卖点”不能替代正文，也不能直接进入迁移方向或仿写。

网络搜索结果先按独立来源登记。保存必要事实、短摘录和 URL，不复制整页受保护正文。
