# v0.9.0-rc.1（本地发布候选）

本版本尚未发布。只有发布负责人明确回复“确认发布”后，才允许推送分支、创建标签并建立 GitHub prerelease。

## 本次新增

- 安全更新中心：读取锁定版本索引与发布清单，校验组件大小和 SHA-256，事务式升级并保留回滚能力；显式定位信息异常时安全关闭。
- 内容分析 Skills：频道蒸馏、单视频拆解和原创仿写，包含相应数据契约与本地工具入口。
- 新漫剧工坊 `2.2.0-rc.1`：合并 Production Package 2.1、Seed Audio 在线配音、生产提速和单行字幕。

## 统一安装包

- AI 视频频道生产系统核心：`0.9.0-rc.1`
- 新漫剧工坊：`2.2.0-rc.1`
- YouTube 发布中心：复用已发布且重新校验哈希的 `0.8.0-rc.2`
- Python 运行时：`3.12.13`
- FFmpeg / ffprobe：`8.1.1`

联网安装只从版本锁定的 `v0.9.0-rc.1` Release URL 下载总清单和缺失组件；离线安装要求总清单与四个组件 ZIP 同目录。所有组件在安装前校验大小和 SHA-256。

## 数据与安全边界

- 不包含用户频道、项目、凭据、Token、API Key、OAuth 数据或运行数据。
- 升级、修复、回滚和卸载继续保留独立用户数据目录。
- 本地候选生成过程未执行 OAuth、YouTube 真实上传、Studio 私有数据读取或长期学习写回。
- 安装或升级插件后需要重启 Codex 并新建任务，已有任务不会重新加载新插件版本。
