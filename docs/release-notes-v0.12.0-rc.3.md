# AI 视频频道生产系统 v0.12.0-rc.3

这是 `rc.2` 之后的本地预发布候选。它把 Codex 生成的故事视觉方案变成系统与新漫剧工坊共同校验、共同锁定执行的正式生产合同。

## 本次更新

- 制作设置卡开启图片提示词或视频提示词后，Codex 基于唯一正式配音稿生成 `productionConfig.codexVisualPlan` schema 1.1；用户不需要自己编写整套提示词，也不会增加第二张强制确认卡。
- 视觉计划先完成群像对照、角色身份设计、故事节拍和连续性圣经，再按正式稿顺序完整覆盖逐镜表演、镜头构图、可见情绪信号、地点、服装、关键道具及图片／视频提示词。
- 角色参考固定为 `identity_only`，只锁身份与服装锚点，不锁表情、视线、头部角度、姿势、手势、构图、光线或背景。
- 图片提示词最多 600 字符，视频提示词最多 500 字符；重要情绪必须独占镜头并至少包含两个可见信号，其中至少一个是人物身体信号。
- 新漫剧工坊升级为 `2.5.0-rc.3`，导入并保留视觉计划、角色身份提示词和逐镜锁定提示词，跳过会覆盖它们的旧角色分析与旧提示词生成流程。
- 工坊只执行生成前的确定性绑定与内容哈希校验，不执行生成后的画风、外貌、服装或文字污染视觉识别检查。
- 保留 `rc.2` 的无频道自由创作、直接成稿、36 种画风、首尾帧视频、长项目 12 场景提示词分批和项目级自动上传授权。

## 安全与升级

统一安装器只替换程序组件，不打包、不迁移、不删除或覆盖频道、项目、凭据和运行数据。插件和 Skill 版本变化后需要重启 Codex 并新建任务；已有任务不会重新加载新版工具。

本版本不包含 Google／YouTube OAuth，不执行真实视频上传，也不覆盖已有 GitHub 标签或 Release。
