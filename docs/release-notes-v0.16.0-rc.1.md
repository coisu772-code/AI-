# AI 视频频道生产系统 v0.16.0-rc.1 预发布说明

本候选汇总近期已经完成的生产系统、工坊和发布中心修改。生产系统新增持久化生产历史、工坊全局队列接力、失败提示词分类和同盘成品／发布包硬链接复用；内容工作区、制作交接与发布桥继续执行当前任务授权、正式文稿和最终中文验收边界。Publish Package 保持 `2.1.0`。

新漫剧工坊升级为 `2.9.0-rc.1`。本版增强项目持久化、单行字幕与剪映导出、用户可选音效、图片提示词断点恢复、图片／视频 API 失败切换及自动生产恢复。完整工坊包继续分发 FFmpeg、Python、Node.js `24.15.0`、Wenku8 `5.1.0` 和 Sharp `0.35.3`；VOICEVOX 继续通过工坊内官方 Release 安装入口获取，不把上游程序直接打入统一安装包。

YouTube 发布中心升级为 `0.10.0-rc.1`。本版增强 Publish Package 2.1.0 正式交接、真实上传错误分类与网络诊断，新增独立元数据更新工具和桌面单实例保护。所有上传策略仍需要本次最终中文验收，并继续受冻结频道、隐私状态、OAuth 状态和网络执行授权约束。

本预发布版不包含频道、项目、API Key、Cookie、OAuth 凭据、成片、发布包或运行数据库，不迁移、不删除、不覆盖现有用户数据，也不执行 Google／YouTube OAuth 或真实视频上传。安装或更新后需要完全重启 Codex 并新建任务，才能加载新版 Skills 与 MCP 工具。
