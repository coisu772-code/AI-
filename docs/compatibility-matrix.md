## 发布通道

- `stable`：供明确完成验收的正式版本使用。
- `beta`：供不承诺向后兼容的试用版本使用。

当前 Beta 清单为 `published`，并绑定已通过干净克隆复验的源码提交 `acb8586775804bec25d05cdca74c2d141dea9878`。GitHub 预发布由版本标签触发的验证工作流生成。

## 阶段3未发布候选兼容矩阵

以下能力只属于 2026-08-04 本地 `0.3.0-dev.1` 工作树，不代表新的 GitHub Release。

| 边界 | 阶段3候选 | 兼容结论 |
| --- | --- | --- |
| Source Package | `1.0.0` | 主版本和 Schema 不变；采集细节保存在版本化资产与报告中 |
| 本地工具协议 | `1.0.0` | 阶段2工具保持兼容，仅新增 `source_*` 工具 |
| `system.db` | Schema `1` | 不变 |

| 资料去重 | 平台 ID／规范 URL／SHA-256 | 同身份或同内容复用 Source Package，不重复保存正文资产 |

| 控制中心／工坊／发布中心 | 外部基线 | 不修改控制中心和工坊；发布中心只读频道接口保持阶段2边界 |
