## 发布通道

- `stable`：供明确完成验收的正式版本使用。
- `beta`：供不承诺向后兼容的试用版本使用。

当前清单仍为 `draft`，`gitCommit` 为空；创建远端、推送或发布 Release 前必须取得用户确认。正式发布时应写入真实提交 SHA，重新计算清单哈希，并将状态改为 `published`。
