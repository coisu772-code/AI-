# AI 视频频道生产系统 v0.11.0-rc.3

本预发布版在 `v0.11.0-rc.2` 已验证的安装、制作、发布和便携运行链上更新内容 Skills，重点让“高贴合”与“原创安全”同时可控。

## 主要变化

- `content-deconstruct` 统一提供高贴合迁移、中度重构、大胆创新三档，每档 5 个、共 15 个方向。
- 15 个方向按主角目标、世界／现实规则、核心关系、冲突来源、因果发动机、高潮行动和结局回报执行组内及跨组去重。
- 每个方向包含 `mustPreserve`、`allowedToChange`、`mustRebuild` 和 `protectedExpressionBoundary`，并通过原文核心体验保留门与非换皮原创门。
- `content-rewrite` 按用户确认的改编档位执行；高贴合迁移不再被强制改成同时更换人物、关系、主因果、高潮和结局的自由原创。
- 旧版尚未确认的方向卡需重新生成；已经进入正文的旧项目继续使用原锁，不自动改写。

## 组件兼容

- Publish Package 保持 `2.1.0`，YouTube 发布中心保持 `0.9.0-rc.2`。
- 新漫剧工坊保持 `2.4.0-rc.1`，复用 `v0.11.0-rc.2` 已验证的完整便携资产。
- Python 3.12.13 便携运行时及 Kokoro 可选运行包内容未变化，继续复用已发布并校验的冻结资产。

## 安装与升级

普通 Windows 用户只需下载 `AI-Video-Channel-Production-Unified-Installer-v0.11.0-rc.3.zip`，完整解压后运行 `install.cmd`。安装器从锁定版本 URL 获取总清单，逐项校验文件大小和 SHA-256，再事务式安装全部组件。

升级不迁移、不删除、不覆盖频道、项目、Cookie、OAuth 凭据、任务数据库或其他运行数据。升级完成后必须重启 Codex 并新建任务，以加载新版内容 Skills；工坊与发布中心程序本次未变更，但若正在运行，可一并重启以保证所有组件使用同一安装版本。

## 安全边界

本 Release 不包含 Token、API Key、Cookie、OAuth 凭据、频道、项目、角色、音频、图片、视频或任务数据库。本次验收不执行 Google/YouTube OAuth、真实视频上传、用户数据迁移或远端删除。
