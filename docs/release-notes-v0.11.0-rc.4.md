# AI 视频频道生产系统 v0.11.0-rc.4

本预发布候选在 `v0.11.0-rc.3` 已验证的三档迁移、安装、制作和发布链上，修复视频或文本仿写偏离来源以及新任务误继承自动授权的问题。

## 主要变化

- 视频链接、文章、本地文件或正文只要包含拆解／仿写意图，固定执行 `content-source → content-deconstruct`；只有用户明确要求时才进入素材研究与原创重构。
- 拆解包强制包含 `sourceStoryDNA`、`expansionSeams`、三档各 5 个方向、来源事实锚点和 105 组两两去重矩阵。
- 高贴合、中度重构和大胆创新方向分别至少绑定 3、2、1 个有效来源事实锚点；无来源依据的职业、机构、灾难、听证会、系统、追放或打脸模板不能冻结。
- 方向使用来源自适应因果阶段，不再套固定九段式；仿写严格读取当前项目已确认的短篇／长篇范围，不再使用统一四章或固定字数默认值。
- 审核模式拆解完成固定停在 `D2_DECONSTRUCTION`，方向选择状态为 `AWAITING_USER`；用户确认前不得进入初稿。
- 新任务默认从干净审核状态开始；自动执行授权只对当前任务有效，频道预设固定为审核模式和 `REQUIRE_REVIEW`。

## 组件兼容

- Publish Package 保持 `2.1.0`，YouTube 发布中心保持 `0.9.0-rc.2`，正式发布中心交接与最终中文验收门继续保留。
- 新漫剧工坊保持 `2.4.0-rc.1`，复用 `v0.11.0-rc.2` 已验证的完整便携资产。
- Python 3.12.13 便携运行时及 Kokoro 可选运行包内容未变化，继续复用已发布并校验的冻结资产。

## 安装与升级

普通 Windows 用户只需下载 `AI-Video-Channel-Production-Unified-Installer-v0.11.0-rc.4.zip`，完整解压后运行 `install.cmd`。安装器只从版本锁定的 Release URL 获取清单，逐项校验大小和 SHA-256，再事务式安装。

升级不迁移、不删除、不覆盖频道、项目、Cookie、OAuth 凭据、任务数据库或其他运行数据。升级完成后必须重启 Codex 并新建任务，以加载新版内容 Skills。

## 安全边界

本候选不包含 Token、API Key、Cookie、OAuth 凭据、频道、项目、角色、音频、图片、视频或任务数据库。本次验收不执行 Google/YouTube OAuth、真实视频上传、用户数据迁移或远端删除。
