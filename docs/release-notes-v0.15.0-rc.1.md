# AI 视频频道生产系统 v0.15.0-rc.1 预发布说明

本候选为每个新制作任务增加三种必须由用户本次选择的生产模式：极速自动、平衡（推荐）和精品导演。模式不能从旧任务、旧项目、频道预设或自动上传授权继承。极速与平衡固定使用静态自动成片；平衡模式由工坊生成图片提示词，只有精品导演生成完整 Codex 视觉计划并开放视频提示词与镜头视频范围。三种模式共享单资产恢复与最小范围 Codex 接管规则，失败时不会默认重跑整个项目。

新漫剧工坊升级为 `2.8.0-rc.1`。独立快捷配音支持 VOICEVOX 音色刷新、试听、分段合成、真实进度，以及按最终音频时长生成单行自然字幕；它不会启动图片、视频或发布流程。视觉提示词升级为精简 V6 合同，单请求最多 12 镜，全片共享最多 20 个并发请求，并通过串行提交保护跨集并发结果不互相覆盖。

完整工坊包继续分发 FFmpeg、Python、Node.js `24.15.0`、Wenku8 `5.1.0` 和 Sharp `0.35.3`。VOICEVOX 因上游分发条款不直接打入安装包，工坊保留从官方 Release 一键安装的入口。Publish Package 保持 `2.1.0`，YouTube 发布中心保持已验证兼容的 `0.9.0-rc.4`。

本预发布版不包含频道、项目、API Key、Cookie、OAuth 凭据或运行数据，不迁移、不删除、不覆盖现有用户数据，也不执行 Google／YouTube OAuth 或真实上传。安装或更新后需要重启 Codex 并新建任务，才能加载新版 Skills 与 MCP 工具。
