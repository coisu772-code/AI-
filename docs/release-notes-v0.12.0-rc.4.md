# AI 视频频道生产系统 v0.12.0-rc.4

这是本地预发布候选版本；代码推送已获授权，但本轮没有创建 Git 标签或 GitHub Release。

## 主要变化

- 口播稿必须确认正式标题；非中文标题必须附中文审核对照，发布标题默认继承口播标题。
- 简介、Hashtags 和自定义封面改为可选；缺省时使用空简介、空标签和 YouTube 自动封面。
- 角色参考图只允许单画布、单角色、单次出现、单一视角和单套主服装。
- 工坊按真实 TTS 时长拆分锁定视觉方案中的镜头，并使不匹配的新旧宫格、镜头视频和成片引用失效。
- 工坊新增平滑复合图片运动；短视频不循环回起点，允许小幅安全减速，时长差距过大时暂停而不是长时间冻结末帧。
- 发布中心兼容可选简介、Hashtags 和自定义封面；没有封面时跳过封面上传。

## 组件版本

- AI 视频频道生产系统：`0.12.0-rc.4`
- 新漫剧工坊：`2.5.0-rc.4`

## 数据与安全边界

- 不包含、不修改、不迁移用户频道、项目、凭据和运行数据。
- 不执行 Google／YouTube OAuth，不进行真实视频上传。
- 更新 Skills 与 MCP 后需要重启 Codex，并在新任务中验证新版工具清单。
