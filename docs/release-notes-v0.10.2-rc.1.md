# AI 视频频道生产系统 v0.10.2-rc.1

本候选版解决其他电脑上“工坊不生成画面”和“发布中心永远停在测试/审核状态”的跨组件连接问题。

主要变化：

- 工坊交接目标自动落入安装版本声明的隔离目录。
- Production Profile 完整合同会转换成工坊能验证的标准来源锁，不再因字段形状不同拒绝生产包。
- 首次建库明确确认动态分镜范围；需要自动成片时不会被静默保存为静态封面模式。
- 正式发布包进入 YouTube 发布中心主数据库，发布中心可继续使用已有 OAuth、频道策略和自动上传调度。
- Codex 本地桥仍固定不联网；它不会代替用户授权，也不会直接调用 YouTube API。
- 约束目录采用跨平台换行归一化 SHA-256，避免同一文件在不同电脑上被误判不一致。

升级说明：通过统一安装器或内置“系统更新”Skill 升级。程序文件按版本替换，频道、项目、OAuth 凭据和任务数据库保留在独立数据目录。升级后重启 Codex 和 YouTube 发布中心，并新建任务加载新 Skills。

本地验收不包含 Google/YouTube OAuth 或真实视频上传；这些操作仍需单独明确批准。
