# AI 视频频道生产系统 v0.12.0-rc.2

这是一个预发布版本。它把新内容任务切换到不绑定频道的自由创作工作区，并把工坊的首尾帧视频能力纳入统一安装包。

## 本次更新

- 新任务默认进入无频道自由创作工作区。热点研究、链接或文件读取、临时提示词、写作、修改与包装可以按用户实际需要自由组合。
- 热点选择卡必须带来源、日期、公开趋势依据和中文解释；用户确认前不会提前生成故事。
- 当前任务的外部提示词只保存路径、SHA-256、用途、顺序和字段映射，不复制进插件或安装包。
- 旧 `content-deconstruct`、迁移／仿写方向和旧 8 方向入口退役。视频或文章链接默认只取得可追溯正文；用户明确要求完整正文并提供充分来源、临时提示词、题材或创作授权时，可直接进入 `direct-draft`，不再强制先确认大纲；只有明确按大纲写作时才要求不少于 80 字的创作简报／故事大纲。
- 用户否决旧模板或要求重新开始时，当前文档版本会被持久标记为不可复用，不能重新确认或换名回流到后续写作。
- 内容阶段不再提前询问配音、宫格、画风或视频设置。用户明确开始制作后，才统一确认频道、正式文稿、配音、36 种故事图片画风、图片／视频提示词和镜头视频范围。
- 新漫剧工坊升级到 `2.5.0-rc.2`，增加首尾帧视频模式、平滑图片运动，并继续兼容书籍导入、生产设置与完整便携运行组件。图片提示词单次处理量从 40 个场景降为 12 个，并发仍为 3，避免长项目响应过大，同时保持完整四宫格批次不拆分。包内 FFmpeg 升级到 `8.1.2`，并保留应用许可、GPL 文本、官方构建来源和逐文件组件哈希清单。
- 自动上传授权只能绑定当前任务、当前项目、频道、隐私状态和正式稿版本。最终中文验收卡仍会展示；授权有效且绑定未变化时不重复询问是否上传。Google／YouTube OAuth、配额和远端删除仍是独立安全门。

## 升级说明

统一安装器只替换程序组件，不打包、不迁移、不删除或覆盖频道、项目、凭据和运行数据。安装完成后需要重启 Codex 并新建任务，已有任务不会重新加载新版插件工具。

本版本不包含 Google／YouTube OAuth，也不会执行真实视频上传。
