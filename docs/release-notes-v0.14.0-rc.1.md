# AI 视频频道生产系统 v0.14.0-rc.1 预发布说明

本候选把生产系统与新漫剧工坊的视觉、音效和断点续跑合同统一到 Codex 视觉计划 schema 1.5。配音行先按实际视觉时刻组成语义画面组，再建立连续性和分镜；普通拆行、时长、行数上限和非关键战斗阶段不再机械制造镜头。

角色参考新增逻辑人物、外观阶段、生命周期、年龄阶段和参考策略绑定，阻止跨年龄或跨生命阶段误用参考图。纯音效按类别限定有效时长，要求真实活跃音频并支持不完整结果重试，仍不会进入字幕或独占分镜。

新漫剧工坊 `2.7.0-rc.1` 支持最高 20 路生图并发、全局及分集宫格模板、生产包渲染身份 1.4、失败步骤选择性重做、持久化日志压缩、音频补丁、图片 API 失败切换和更强的多方向动态镜头。Publish Package 保持 `2.1.0`，YouTube 发布中心保持 `0.9.0-rc.3`。

本候选不包含频道、项目、凭据或运行数据，也不执行 OAuth 或真实上传。统一安装器、核心包、Python 运行包、工坊与发布中心均按固定版本和 SHA-256 锁定；GitHub 标签与非草稿 prerelease Release 只会在最终发布确认后创建。
